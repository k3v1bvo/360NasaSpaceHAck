# 🛰️ GEO-COCHABAMBA 360 (NASA Space Apps Challenge 2026)

> **Plataforma Unificada de Resiliencia Territorial, Monitoreo Satelital y Alerta Temprana**  
> Fusión de datos satelitales de la **NASA** con datos territoriales abiertos del **Gobierno Autónomo Municipal de Cochabamba (GAMC)**.  
> **Sede:** Feria Exposición de Cochabamba (FEXCO) • Cochabamba, Bolivia  
> **Repositorio Oficial:** [https://github.com/k3v1bvo/360NasaSpaceHAck.git](https://github.com/k3v1bvo/360NasaSpaceHAck.git)

## 🚀 Inicio Rápido para el Equipo

```bash
# 1. Clonar el repositorio
git clone https://github.com/k3v1bvo/360NasaSpaceHAck.git
cd 360NasaSpaceHAck

# 2. Cambiarte a tu rama (ejemplo Integrante 2)
git checkout feature/modulo-microclimas

# 3. Instalar y correr el frontend
cd frontend
npm install
npm run dev
```

Abre `http://localhost:5173` en tu navegador.
